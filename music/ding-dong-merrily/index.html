Ding dong! merrily on high

A sing-along score for a single voice: the notes and words light up as they go by. Pick a key that suits your range, then tap any note to start from there.

Tune: Branle de l’Official, from Thoinot Arbeau’s Orchésographie (1589). Words: George Ratcliffe Woodward (1924). Piano: the alto, tenor and bass of Charles Wood’s harmonization (1924), from Klaus Föhl’s CPDL edition.

Hear
Press Play, or tap a note to start from there.

The voice lights up in pink; with the piano part shown, the piano notes light up in gold. Tap any note, in the voice or the piano, to start from there. The verse tune is sung twice per verse (first and second lines, then third and fourth), and the Gloria is repeated.

How it fits together

Each verse uses the same short tune twice, then the Gloria comes round twice. The whole melody sits within one octave: the lowest note is the one on “high” and “in”, the highest is the very first note of “Glo-”. If that top note feels strained, drop the key; if “high” rumbles, raise it.

The Gloria

It is a falling sequence: the same six-note shape, “long-short, four quick”, starting one step lower each bar. Learn the first bar on a neutral “loo”, then simply step it down. Choirs share the breathing, but on your own you need a deep breath before “Glo-” and, if needed, a quick sip at the start of the fifth bar, where the run is halfway down.

Singing it unaccompanied

Untick Piano, or both Voice and Piano, to practise it the way it is usually sung. Use the Starting note button before each attempt, and check yourself at the end of the Gloria: your last note should land back on the same note you started on. If it doesn’t, the usual culprit is the Gloria sagging flat as it descends, so keep each new bar’s first note bright.
